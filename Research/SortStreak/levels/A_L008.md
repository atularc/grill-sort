# A_L008 (Sort Streak, Level 8)

Source: A_L008 (A = Beyond Gamer playlist). 3 contact sheets, 46 frames (~115 s). All frames looked at.

## 1. Header / HUD
- "Level 8", no difficulty label. Back arrow + restart (circular arrow) button top left. Coins 800 -> 920 at the win.
- IQ bar: not present in this player's version (light-blue UI, no 40/90/180 bar).
- Orders counter at start: "0/12". Top shelf shows 10 empty grey pot slots (fills as pots are served, scrolls when more than 10).
- No start banner visible.

## 2. Starting board
- 7 ropes. Pots: white (helper), purple, yellow, blue, red, orange, lilac.
- Rope length 4 slots.
- Flowers top to bottom:
  1. white: red, yellow, blue, red
  2. purple: purple, lilac, ?, lilac
  3. yellow: ?, orange, purple
  4. blue: yellow, purple
  5. red: yellow, red, blue, lilac
  6. orange: orange, purple
  7. lilac: lilac, orange
- 21 flowers, 2 "?". Colours: red, yellow, blue, purple, lilac, orange (6). Green and pink appear later with new ropes.
- Free space: 7 empty slots (28 total).
- Blockers: only "?".

## 3. How it was solved
- Serve order (from the top shelf): orange (1/12), lilac + purple (3/12), yellow (4/12), red (5/12), pink (6/12), blue/light blue (7/12), light blue (8/12), green/others (9/12), ... red last (12/12).
- New ropes arrive full (4 flowers), some with "?". When the queue runs out the board shrinks: 7 -> 5 -> 3 ropes; the last frames show 2 empty white ropes + the red rope.
- Boosters (bottom): Undo "FREE" (greyed until the first move), Hint (bulb) 3, Add Rope (ring) 1. None used; counts stay 3 and 1.
- Messages: "This rope can't hold that many flowers." (sheet 1 end), "Match the bottom flower to drop here!" (sheet 2).
- Praise: "Great!", "Excellent!", "Unstoppable!", "Legendary!".
- Some hesitation around 5/12 (several near-identical frames).
- ~40-45 moves (estimate), ~110 s.

## 4. End of level
- Board dims, then "Amazing!" with a big flower bouquet and a blue "Level 9" button. Coins 800 -> 920 (+120).
- No other popups.

## 5. Design notes
- Compare B_L008: same level number but a DIFFERENT starting board (B: pots white, yellow, blue, orange, red, lilac, pink, 4 "?"). Both have 7 ropes x 4, 21 flowers, 7 free slots, 0/12. Looks like an A/B variant or a different game version (A has the older blue UI without IQ bar).
- Easy: 7 free slots, only 2 "?", short ropes.
- Look-alikes: purple vs lilac, red vs orange.
