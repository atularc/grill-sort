# Level analysis template (fill one file per video: levels/<tag>.md)

Source: <tag> (A = Beyond Gamer playlist, B = Sort Streak Walkthrough playlist), video length, frames looked at.

## 1. Header / HUD
- Level number, difficulty label under it (none / "Hard" / "Super Hard" / other), coins shown.
- IQ bar? Its milestones (e.g. 40 / 90 / 180) and how far it fills by the end.
- Orders counter at start ("0/N") = total orders (pots) in the level.
- Any banner at level start (e.g. "N Streak! You're on a roll!", tips, tutorial text). Quote the text exactly.

## 2. Starting board (use the _start image, and the first sheet frames)
- Number of ropes, and which pot colour sits above each (white = helper rope).
- Rope length (how many flower slots each rope has; say if ropes differ).
- Flowers on every rope, top to bottom, e.g. `blue, ?, red, red` ("?" = mystery flower). Count colours used.
- Empty slots in total at the start (the free space).
- Special pieces / blockers: mystery "?", vines, locks, ice, chains, keys, anything else. Describe the look and what condition is shown on them (number, colour icon, etc.).

## 3. How it was solved (go through every sheet frame in order)
- The order in which pots were served; any order that came back (same colour twice).
- How new ropes arrive after a serve (full? with "?"?), and what happens when the queue runs out.
- When each blocker opened and why (what condition met it).
- Boosters shown and their counts (Undo / Hint / Add Rope / Reset / others), and whether any was used.
- Any rejection messages ("This rope can't hold that many flowers.", others), "Nice!", "Perfect!", "Good Luck!" or other praise; quote them.
- Moments the player hesitated or undid (frames with no change, Undo count dropping).
- Rough number of moves (count board changes across frames) and time to solve.

## 4. End of level
- Win screen(s): text, rewards (coins, multiplier, chest, streak), collection screens, buttons.
- Any popup after the level (rate us, notifications, new feature unlocked, booster unlocked, ads, events, piggy bank, offers). Quote text.

## 5. Design notes
- What makes this level easy or hard (free space, colours, mystery count, blockers, queue length, look-alike colours).
- Anything NEW compared with earlier levels (first time a mechanic, booster, UI element or popup appears).
- UI / UX details worth copying or avoiding.

Be factual: only write what the frames show. Write "not visible" when you can't tell.
